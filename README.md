# Lukas Vis Portfolio

This is a portfolio website built using Svelte. Originally built with NextJs and then ported for easier development experience.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

## Building for Production

To build the static site:

```bash
npm run build
```

The built files will be in the `build` directory.

## Features

- **Home Page**: Landing page with logo and navigation links
- **Resume Page**: Detailed work experience and education
- **Music Portfolio**: Showcase of music projects and releases
- **Theme Toggle**: Dark/light mode support
- **Responsive Design**: Mobile-friendly layout
- **Tech Badges**: Visual representation of technologies used
- **Dotted Background**: Animated background effect (optional)

## Tech Stack

- SvelteKit
- TypeScript
- Tailwind CSS
- FontAwesome
- SCSS

## Deployment

The site can be deployed as a static site using:

```bash
npm run deploy
```

This will build the site and deploy it to GitHub Pages.
